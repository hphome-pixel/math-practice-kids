# 金幣數學島

給小朋友練習直式加法、減法的靜態網頁小工具。

## 功能

- 題型：加法、減法、加減混合、乘法、除法
- 位數：個位、十位、百位、千位
- 乘法設定：1 到 9 的單一乘法表、十位乘法、百位乘法
- 乘法表背誦：可以查看 1 表到 9 表
- 除法設定：除以 1 到 9、十位除法
- 小遊戲：打怪練習和拼圖解鎖都可選加法、減法、乘法或混合題型
- 拼圖解鎖：隨機解鎖 9 片圖片，完成後停留在拼圖畫面再看成績
- 加減法難度：可選不進位、有進位、不借位、有借位
- 限時模式：可自訂秒數並連續答題
- 鼓勵音效：可開關答題提示音
- 每日練習紀錄：用瀏覽器記錄今天練了幾題和答對率
- 結果頁會顯示答題紀錄，也可以只練錯題
- 題目用直式顯示
- 可以用手指在答案格寫答案
- 可以點辨識出的答案數字手動修正
- 題目上方有進位、借位草稿格
- 十位除法下方有手寫草稿格，方便小朋友計算
- 每輪 10 題
- 測驗中可以停止並回主選單
- 立即顯示答對或正確答案
- 練習結束後顯示分數
- 手機、平板、電腦都可以使用
- 關於、隱私權政策、聯絡我們頁面，方便網站公開和廣告審核
- 第一階段雙語：首頁可切換繁體中文 / English，資訊頁提供英文版
- 角色養成頁：可選正式 PNG 角色資產小男孩或小女孩，角色本體先採基本上衣、下衣與鞋子，方便後續換裝
- 首頁改為遊戲大廳：角色舞台、等級 XP、寶箱與開始冒險優先顯示，練習設定預設收合
- 首頁品牌改為金幣數學島，練習設定入口加大並加上調整提示
- 裝備抽取制：寶箱改為抽裝備，依目前性別套用對應完整角色造型
- 角色造型圖：支援 common / rare / epic / legendary，初始角色使用 `boy_basic.png` 和 `girl_basic.png`
- 角色收藏：作為圖鑑查看，換造型以物品裝備為主
- 遊戲狀態：金幣、XP、等級、連勝、Combo 與角色收藏統一由 gameState 管理
- 寶箱系統：金幣開寶箱，裝備依 common / rare / epic / legendary 稀有度掉落，重複裝備轉金幣
- 裝備路徑：`assets/characters/Inventory/Common|Rare|Epic|Legendary/`
- 造型對應：睡衣、運動鞋、貓咪、舞會面具、勇者之劍、魔法棒會切換男女對應造型
- Legendary 裝備新增天使翅膀，支援男女對應 MP4 角色動畫
- 角色互動：點擊角色預覽會播放影片或彈跳動畫，裝備物品後會播放裝備音效並捲回角色預覽
- 重複裝備返還寶箱價格 50% 金幣
- 等級限定卡：達到指定等級後可從角色收藏領取問號卡
- 成就限定卡：加減乘除答對數達標後可領取專屬問號卡
- 回合獎勵寶箱：完成一輪後可領寶箱，點擊後隨機掉裝備，重複裝備會轉成金幣
- 成績頁領獎：先看完成績，再手動領取寶箱，開箱有延遲、音效與稀有度演出
- 答對回饋：每題答對會即時加金幣並顯示飛幣動畫
- Combo：連續答對 3 / 5 / 10 題會在題目上方出現 Nice / Great / Amazing 動畫
- 角色頁改為遊戲背包式資訊，顯示等級、XP、連勝、寶箱與角色收藏
- 寶箱與 GM 測試：可用 10 金幣抽角色，也可快速加金幣、解鎖全部、測試寶箱和重置角色
- 打怪練習：每輪 10 題固定一隻怪物，吸血鬼、狼人、殭屍會逐輪輪替
- 打怪動畫：答對會出現攻擊特效與受擊動作，答錯顯示 MISS 與跳避動作
- 設定頁顯示版本號，方便確認目前部署版本

## 使用方式

直接打開 `index.html` 就可以使用。

## 放到 GitHub Pages

1. 建立 GitHub repo，例如 `math-practice`
2. 上傳這個資料夾裡的檔案
3. 到 repo 的 `Settings` → `Pages`
4. Source 選 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/root`
6. 儲存後等 GitHub 產生網址
