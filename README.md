# 數學練習

給小朋友練習直式加法、減法的靜態網頁小工具。

## 功能

- 題型：加法、減法、加減混合、乘法
- 位數：個位、十位、百位、千位
- 乘法設定：1 到 9 的單一乘法表、十位乘法
- 題目用直式顯示
- 可以用手指在答案格寫答案
- 題目上方有進位、借位草稿格
- 每輪 10 題
- 測驗中可以停止並回主選單
- 立即顯示答對或正確答案
- 練習結束後顯示分數
- 手機、平板、電腦都可以使用

## 使用方式

直接打開 `index.html` 就可以使用。

## 放到 GitHub Pages

1. 建立 GitHub repo，例如 `math-practice`
2. 上傳這個資料夾裡的檔案
3. 到 repo 的 `Settings` → `Pages`
4. Source 選 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/root`
6. 儲存後等 GitHub 產生網址
